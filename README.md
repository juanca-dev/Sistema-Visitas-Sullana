# 🏛️ Sistema de Visitas Digital - Sullana
Sistema profesional desarrollado en **PHP y MySQL** para el control de ingresos y salidas.

### ✨ Características:
* **Dashboard en tiempo real:** Estadísticas de ingresos, egresos y personas en planta.
* **Integración RENIEC:** Autocompletado de datos por DNI mediante API.
* **Reportes:** Exportación de historial a **Excel** y **PDF**.
* **Seguridad:** Control de acceso por roles (Admin/Portería).

### 🛠️ Tecnologías:
PHP 8+, MySQL, Materialize CSS, JQuery, FPDF.
